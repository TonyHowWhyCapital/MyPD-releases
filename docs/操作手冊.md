# MyPD 操作手冊

適用版本：MyPD 1.2.0（macOS 與 Windows）。

本手冊分成兩份。這一份說明基本概念、介面、建模流程、資料庫連線、PDM 檔案、DDL 與版本管理。快捷工具、匯入匯出、表格功能、設定、快捷鍵與常見問題請看 [操作手冊：進階工具與參考](操作手冊-進階工具.md)。安裝、Java 設定與第一次啟動請看 [安裝手冊](安裝手冊.md)。

本手冊中以「」標示的文字，是 MyPD 在繁體中文介面上顯示的選單、按鈕、頁籤或對話框名稱。箭頭表示選單的層級，例如「匯入」→「從資料庫逆向匯入」表示先點「匯入」，再在展開的選單中點「從資料庫逆向匯入」。

## 1. 認識 MyPD

MyPD 是桌面版的資料庫建模工具。您可以在 MyPD 中設計資料表、欄位、索引、關聯與關係圖，再產生 DDL、文件與報表。MyPD 以開源專案 PDManer 4.9.3 為基礎，並加入影響分析、模型比較與合併、資料庫物件、報表、資料表範本、PDM 檔案直接編輯等功能。

### 專案檔案

一個專案就是磁碟上的一個 JSON 檔案，副檔名為 `.pdma.json`，例如 `訂單系統.pdma.json`。資料表、欄位、關係圖、資料字典、資料域、資料庫連線與專案層級的設定都存在這個檔案中。

- MyPD 也能開啟舊版的 `.chnr.json` 檔案，以及 PowerDesigner 的 `.pdm` 檔案。PDM 檔案的規則不同，請看第 5 節。
- 資料庫連線的使用者名稱與密碼也存在專案檔案中。把專案檔案交給別人之前，請先確認其中的連線資訊可以分享。

### 儲存、自動儲存與備份

MyPD 預設不會自動儲存。請按工具列的「儲存」，或按 Cmd+S（macOS）或 Ctrl+S（Windows）。若要定時自動儲存，請到「設定」→「系統參數」→「自動儲存」選擇間隔，可選 2 到 60 分鐘。

每次儲存 `.pdma.json` 專案（含自動儲存），MyPD 都會在專案檔案旁邊多存一份快照。MyPD 會在專案檔案所在的資料夾建立下列檔案與資料夾：

| 位置 | 內容 | 何時產生 |
|------|------|----------|
| `.back_<專案名>/T<時間>.pdma.json` | 儲存當下的完整快照，最多保留 100 份，超過時刪除最舊的一份 | 每次儲存或自動儲存 |
| `.version_<專案名>/` | 版本管理記錄的版本 | 在「版本管理」記錄版本時 |
| `<專案名>-backup-<時間>.chnr.json` | 異常時的緊急備份 | 視窗當掉或沒有回應時 |
| `<檔名>.pdm.bak` | PDM 原始檔案的備份 | PDM 檔案第一次被修改並儲存前 |

`.back_` 資料夾中的快照可以在工具列的「操作歷史」中檢視與還原，請看進階手冊的「操作歷史」一節。

### 離線執行

MyPD 不需要網路。自動更新、使用統計、雲端功能與遠端讀取都已移除。視窗內的網路請求只允許讀取本機資源，其餘一律攔截。只有在您自己設定資料庫連線並執行連線相關功能時，Java 引擎才會連到該資料庫。

唯一的例外是新版本檢查：程式啟動時向 GitHub 查詢最新版本號，有新版時在首頁左下角顯示下載連結，不會自動下載或安裝，也不傳送任何專案或使用者資料。取消勾選首頁左下角的「啟動時自動檢查」後，程式完全離線。

### 哪些功能需要 Java

下列功能透過 Java 引擎執行。電腦上沒有 Java，或找不到引擎檔案時，這些功能會顯示錯誤，其他功能不受影響。Java 的安裝與設定請看 [安裝手冊](安裝手冊.md)。

- 資料庫連線的「測試」。
- 「從資料庫連線逆向解析」與「從資料庫逆向產生 PDM 檔案」，含讀取伺服器上的資料庫清單。
- 「模型比較與合併」中選擇「資料庫」的一側，以及「版本管理」中的「資料庫比較」。
- 「從EXCEL檔案」匯入、「匯出EXCEL文件」、「匯出為WORD文件」。
- 「從DDL檔案逆向解析」。

PDM 檔案的開啟、匯入與匯出、HTML 文件、報表、圖片與 DDL 匯出都不需要 Java。

## 2. 介面導覽

### 首頁

啟動 MyPD 後會先看到首頁。左側是操作列，右側是清單。

- 「新增專案」：建立新的專案檔案，請看 3.1 節。
- 「開啟」：選擇 `.pdma.json`、`.chnr.json` 或 `.pdm` 檔案開啟。
- 「最近開啟」：最近開啟過的專案。
- 「參考範本」：MyPD 內附的範例專案，可以開啟來參考。範本開啟後標題列會顯示「目前專案為範本專案」。儲存範本時，MyPD 會要求您另存成新的專案檔案。

清單上方有搜尋框，可依專案名、專案描述或位置篩選。右上角的兩個圖示切換「卡片顯示」與「清單顯示」，MyPD 會記住您的選擇。

在「清單顯示」中，每列顯示「專案名稱」、「專案描述」、「檔案修改時間」、「大小」與「位置」。點「專案名稱」或「檔案修改時間」的標題可以排序，第三次點擊回到原本的開啟順序。檔案已不存在的專案會顯示「檔案不存在」。點專案名稱或連按兩下該列即可開啟。「操作」欄的圖示依序為：

| 圖示說明 | 作用 |
|----------|------|
| 「在資料夾中顯示」 | 在 Finder 或檔案總管中顯示專案檔案 |
| 「專案資訊」 | 檢視專案名、描述、建立時間與更新時間 |
| 「編輯專案」 | 修改專案名、儲存位置、描述與圖示 |
| 「以唯讀模式開啟」 | 開啟專案但不能修改，工具列與「版本管理」頁籤會隱藏 |
| 「移除」 | 只從清單移除，不刪除檔案 |
| 「檔案從磁碟刪除」 | 從硬碟刪除專案檔案，刪除前會再確認一次 |

在「卡片顯示」中，把滑鼠移到卡片上，會出現同樣的資訊、編輯與更多操作圖示。

### 主視窗

開啟專案後進入主視窗，由上到下、由左到右分成四個區域。

**標題列與工具列。** 最左邊的左箭頭圖示關閉專案並回到首頁。專案有未儲存的修改時，MyPD 會先顯示「關閉專案確認」。箭頭右邊是專案名稱，再右邊是工具列，最右邊是全域搜尋框，可以搜尋資料表、邏輯實體、多表透視、資料字典與欄位。

工具列按鈕依序如下：

| 按鈕 | 作用 |
|------|------|
| 「儲存」 | 儲存專案。旁邊的下拉選單有「另存為」 |
| 「重新整理」 | 從磁碟重新讀取專案，未儲存的修改會遺失 |
| 「新表」、「邏輯實體」、「群組」、「形狀」、「心智圖」 | 拖到關係圖上新增物件，只在目前頁籤是關係圖時可用 |
| 「對齊」 | 對齊關係圖上選取的多個物件 |
| 「快捷工具」 | 比較、編輯、輸出與顯示類的工具，請看進階手冊第 7 節 |
| 「匯入」、「匯出」 | 各種匯入與匯出，請看第 4、5 節與進階手冊第 8 節 |
| 「設定」 | 開啟「設定」對話框，請看進階手冊第 10 節 |
| 「資料庫」 | 開啟「資料庫連線設定」，請看第 4 節 |
| 「操作歷史」 | 檢視與還原每次儲存的快照 |

**左側頁籤。** 視窗最左邊一列只顯示圖示，滑鼠停在圖示上會顯示名稱：

| 頁籤 | 內容 |
|------|------|
| 「模型」 | 模型樹：資料表、邏輯實體、多表透視、關係圖、資料字典 |
| 「型別設定」 | 基本資料型別、資料域與資料庫類型 |
| 「程式碼產生器」 | 各程式語言的程式碼範本 |
| 「版本管理」 | 模型版本與資料庫比較，請看 6.4 節 |
| 「規範檢查」 | 依規則檢查資料表與欄位的命名 |

**模型樹。** 「模型」頁籤的標題為「資料模型」。樹的最上方是「首頁封面」。標題列右側有三個控制項：

- 準心圖示「定位到開啟的分頁」：在樹中找到目前開啟的物件。
- 眼睛圖示「隱藏/顯示空目錄」：隱藏沒有內容的分類。
- 「主題領域模式」核取方塊：勾選後依主題領域分組顯示，請看 3.10 節。

展開某個分類後，分類右側會出現排序圖示。每點一次，依序切換為按代碼排序、按名稱排序與原始順序，滑鼠停在圖示上會顯示目前的排序方式。每個分類各自記住排序方式，記在這台電腦上。在樹中按住 Cmd 或 Ctrl 點擊可以多選，按住 Shift 點擊可以選取連續項目。在項目上按右鍵可以新增、複製、剪下、貼上、刪除或改變主題領域。

左側區域的右邊緣可以拖曳調整寬度，雙箭頭圖示可以收合左側區域。

**分頁編輯區。** 在模型樹中連按兩下物件，會在右側開啟一個分頁。分頁的顏色與首頁的導覽列一致。在標籤上按右鍵可選「關閉目前」、「關閉其他」或「關閉所有」。關閉有未儲存修改的分頁時，MyPD 會先確認。

### 切換語言

MyPD 支援簡體中文、繁體中文與 English，預設跟隨作業系統的語言。

1. 開啟任一專案。
2. 按工具列的「設定」。
3. 選擇「系統參數」頁籤。
4. 在「語言」選擇「跟隨系統」、「簡體中文」、「繁體中文」或「English」。
5. 按「確定」。

語言設定存在這台電腦上，不會寫進專案檔案。

**專案內容會跟著語言。** 開啟專案或切換語言時，專案中仍是內建預設值的名稱會換成目前語言的名稱；介面是繁體中文時，簡體中文的模型內容也會轉成繁體中文，並在下次儲存時寫回專案檔案。第一次以繁體中文開啟簡體專案前，請先備份。詳細規則請看進階手冊 10.5 節。

### 白天與夜間模式

按「快捷工具」→「顯示」→「夜間模式」切換成深色介面。在夜間模式中同一位置顯示「白天模式」，可以切回來。這個設定存在專案檔案中，儲存專案後下次開啟仍會保留。

### 縮放整個介面

| 按鍵（macOS 用 Cmd，Windows 用 Ctrl） | 作用 |
|----------------------------------------|------|
| Cmd 或 Ctrl 加 `+`（或 `=`） | 放大介面 |
| Cmd 或 Ctrl 加 `-` | 縮小介面 |
| Cmd 或 Ctrl 加 `0` | 恢復原始大小 |

這組按鍵縮放整個視窗，與關係圖的畫布縮放無關。

## 3. 建立資料模型

### 3.1 建立專案

1. 在首頁按「新增專案」。
2. 在「新增專案」對話框填寫「專案名」，並在「儲存位置」選擇資料夾。這兩項必填。
3. 視需要填寫「描述」，或在「圖示」選擇圖示。沒有填「描述」時，MyPD 以專案名作為描述。
4. 按「確定」。

MyPD 在所選資料夾建立 `<專案名>.pdma.json` 並開啟它。同名檔案已存在時，MyPD 顯示「專案已經存在」並停止。

### 3.2 選擇資料庫類型

新專案的預設資料庫是 MySQL。預設資料庫決定欄位顯示哪一種資料庫的資料型別，也決定 DDL 預設用哪一種語法。要變更預設資料庫，可以用下列任一方法：

- 在「型別設定」頁籤展開「資料庫」，連按兩下要用的資料庫，在「編輯資料庫」對話框勾選「預設資料庫」，再按「確定」。
- 在資料表的「資料表」頁籤，點欄位清單上方「資料庫類型:」後面的資料庫名稱。在「切換資料庫類型」對話框選擇資料庫，按「確定」。
- 在「資料庫連線設定」選擇預設連線並按「確定」。專案的資料庫類型會跟著連線改變，MyPD 會顯示提示，說明資料庫類型已改成哪一種。從資料庫逆向匯入時也一樣。

### 3.3 建立資料表

1. 在「模型」頁籤的「資料表」分類上按右鍵，選「新增資料表」。
2. 在「代碼」輸入表名，最多 64 個字元。這一項必填。
3. 在「顯示名稱」輸入中文名稱，最多 32 個字元。
4. 在「建立方式」選擇建立方式：
   - 「空表」：從「設定」→「表設定」→「預設欄位」中的欄位開始。
   - 「繼承」：選擇「父表」，再點「父表欄位」選擇要帶入的欄位。
   - 「從範本建立」：選擇一個「範本」。勾選「保持與範本的關聯」後，日後可以用範本同步這張表的欄位。這個選項只在專案已有資料表範本時出現，範本的建立方法請看進階手冊。
5. 在「所屬主題領域」選擇一個或多個主題領域。
6. 按「確定」。

新的資料表會在右側開啟一個分頁。資料表編輯畫面有這些頁籤：「資料表」、「索引」、「鍵」、「資料庫程式碼」、「程式碼」與「規範檢查」。

在關係圖頁籤中，也可以把工具列的「新表」拖到畫布上，直接在圖上建立資料表。

### 3.4 編輯欄位

在「資料表」頁籤，上半部是「代碼」、「顯示名稱」、「說明」等基本資訊，下半部是「欄位明細」。欄位的主要欄位有：

| 欄位 | 說明 |
|------|------|
| 「欄位代碼」、「顯示名稱」、「說明」 | 欄位名稱、中文名稱與註解 |
| 「資料域」 | 選擇資料域後，型別、長度與小數位數跟著資料域 |
| 「資料型別」、「長度」、「小數位數」 | 不使用資料域時直接填寫 |
| 「主鍵」、「不可為空」、「自動遞增」 | 核取方塊 |
| 「預設值」 | 欄位預設值 |
| 「資料字典」 | 讓欄位對應到一個資料字典 |
| 「關係圖」 | 是否在關係圖中顯示這個欄位 |

欄位清單上方的按鈕依序為「頂」、「上」、「下」、「底」（移動選取的欄位）、「增」（新增欄位）、「刪」（刪除選取的欄位）。把滑鼠移到資訊圖示上可以看到操作提示：

- 點列號選取一列。按住 Ctrl 點列號跳著選，按住 Shift 點列號選連續的列。
- 選取列之後，Ctrl+C 複製，Ctrl+V 貼上。macOS 也可以用 Cmd。
- 在儲存格中按 Ctrl+Shift+U 切換英文大小寫。
- 選取多列後可以一次調整資料域。

在「資料域」儲存格的下拉清單選「＋ 新增資料域…」，可以當場建立新的資料域並套用到這個欄位。

欄位清單也支援欄位選擇、拖曳排序、多欄排序與調整欄寬，請看進階手冊第 9 節。

### 3.5 主鍵與替代鍵（唯一約束）

主鍵由欄位清單的「主鍵」核取方塊決定。勾選多個欄位就是複合主鍵。

「鍵」頁籤列出這張表的鍵。第一列是「主鍵」，欄位跟著「主鍵」核取方塊，不能在這裡修改。您可以在這裡填寫主鍵的「條件約束名稱」。

要建立唯一約束（替代鍵）：

1. 開啟資料表的「鍵」頁籤。
2. 按「新增替代鍵」。MyPD 以 `AK_<表名>_<序號>` 命名。
3. 視需要修改「名稱」、「代碼」與「條件約束名稱」。
4. 在「欄位」選擇組成這個鍵的欄位，可以多選。

替代鍵會寫進建表 DDL，成為唯一約束。按該列最右邊的垃圾桶圖示可以刪除替代鍵。

### 3.6 索引

1. 開啟資料表的「索引」頁籤。
2. 按「增」新增一個索引，填寫「索引名」、「是否唯一」與「描述」。
3. 展開這個索引，在它的欄位清單按「增」。
4. 在「引入」對話框勾選要放進索引的欄位，按「確定」。
5. 為每個欄位選擇排序方向，預設為遞增。

### 3.7 資料型別與資料域

「型別設定」頁籤有三個分類：

- 「基本資料型別」：一種邏輯型別在每一種資料庫中的實際型別，例如同一個字串型別在 MySQL 是 `VARCHAR`，在 Oracle 是 `VARCHAR2`。
- 「資料域」：可重複使用的欄位型別定義，含基本資料型別、長度、小數位數、預設值、不為空與備註。欄位套用資料域後，修改資料域就會改到所有使用它的欄位。
- 「資料庫」：MyPD 支援的資料庫類型與各自的 DDL 範本。

要新增資料域，在「資料域」分類上按右鍵選「新增資料域」，填寫「資料域代碼」、「顯示名稱」、「資料型別」、「長度」、「小數位數」等欄位後按「確定」。連按兩下現有的資料域可以修改。

### 3.8 資料字典

資料字典是代碼對照表，例如性別代碼 `M` 與 `F`。

1. 在「資料字典」分類上按右鍵，選「新增字典」。
2. 填寫「字典代碼」、「顯示名稱」、「所屬主題領域」與「描述說明」。
3. 在「字典條目」加入每一個代碼，填寫「條目代碼」、「條目顯示名稱」、「排序碼」等欄位。
4. 在資料表欄位的「資料字典」選擇這個字典，讓欄位與字典建立關聯。

「匯出」→「匯出SQL」→「匯出資料字典SQL」可以產生字典資料的 SQL，格式由「設定」→「資料字典SQL範本」決定。

### 3.9 多表透視（資料庫的 view）

介面上的「多表透視」就是資料庫的 view。

1. 在「多表透視」分類上按右鍵，選「新增多表透視」。
2. 在「選擇表」步驟勾選來源資料表，按「下一步」。
3. 在「選擇欄位」步驟勾選要帶入的欄位，按「下一步」。
4. 在「基本資訊」步驟填寫「多表透視代碼」與「顯示名稱」，按「確定」。

### 3.10 主題領域（分組）

主題領域把資料表、多表透視、關係圖與資料字典分組，適合大型專案依業務區塊整理。

1. 勾選模型樹上方的「主題領域模式」。
2. 樹中沒有任何主題領域時，點「建立主題領域」。已有主題領域時，在主題領域上按右鍵選「新增」。
3. 填寫「主題領域代碼」與「主題領域名稱」，按「確定」。

把物件歸到主題領域的方法：

- 建立資料表時選擇「所屬主題領域」。
- 在物件上按右鍵選「改變主題領域」。
- 在逆向匯入或匯入 PDM 時，在選擇資料表的清單中指定主題領域。下拉清單中的「＋ 新增主題領域…」可以當場建立新的主題領域。

沒有歸入任何主題領域的物件，會顯示在「預設主題領域」之下。

### 3.11 關係圖與關聯

建立關係圖：

1. 在「關係圖」分類上按右鍵，選「新增關係圖」。
2. 填寫「關係圖代碼」與「關係圖名稱」。
3. 在「連線物件」選擇「資料表」或「欄位」。「欄位」表示關聯線連到欄位，「資料表」表示關聯線連到整張表。
4. 選擇「所屬主題領域」，按「確定」。

在關係圖上操作：

- 把模型樹中的資料表拖到畫布上。空白的畫布會提示「從左側資料表中拖曳資料表至關係圖中」。
- 從一張表的欄位連接點拖到另一張表的欄位，建立關聯線。新的關聯線預設為一對多。
- 點選關聯線，會出現浮動工具列，可以設定「關係說明」、「填滿色彩」、「線條型別」、「起點箭頭」與「終點箭頭」（即兩端的基數），以及「更新時」與「刪除時」的參照規則（「未設定」、「不處理」、「限制」、「串聯」、「設為空值」、「設為預設值」）。按鎖頭圖示可以「鎖定」關聯線。
- 在畫布上連按兩下資料表，會開啟該表的編輯面板。面板會填滿主視窗，也可以調整大小。
- 按住 Cmd 或 Ctrl 再捲動滑鼠滾輪可以縮放畫布，按住 Cmd 或 Ctrl 再拖曳可以移動畫布。
- 畫布右上方的工具列有「復原」、「重做」、「選擇/移動」、縮放比例與「小地圖」。點縮放比例可以「重設為100%」。

工具列的「形狀」、「群組」、「心智圖」可以在圖上加入說明用的圖形，「對齊」可以對齊多個選取的物件。這些按鈕只在目前頁籤是關係圖時可用，否則滑鼠停留時會顯示「該功能僅在目前啟用的tab頁為關係圖下可用」。

關係圖的圖片匯出請看進階手冊第 8 節。

### 3.12 刪除前的影響提示

在模型樹中刪除資料表時，「刪除確認」對話框會列出受影響的物件，例如參照這張表的外鍵、包含這張表的多表透視、關係圖與主題領域，最多列出 10 項。要完整分析並保存結果，請使用進階手冊的「影響分析」。

## 4. 資料庫連線與逆向

本節的「測試」與逆向功能都需要 Java，請先依 [安裝手冊](安裝手冊.md) 完成 Java 設定。

### 4.1 建立與測試連線

1. 按工具列的「資料庫」，開啟「資料庫連線設定」。
2. 按「新增」（加號圖示）。
3. 在左側清單的新連線填寫連線名，並選擇資料庫類型。
4. 在右側填寫「driver-class」與「url」，這兩項必填。滑鼠停在資訊圖示上可以看到各種資料庫的「設定範例：」。
5. 填寫「username」與「password」。
6. 若資料庫不是 MySQL、SQL Server、Oracle、PostgreSQL、DB2 或達夢，可能需要在「自訂驅動程式」選擇 JDBC 驅動程式的 `.jar` 檔案。
7. 按「測試」。成功時顯示「連線成功」，失敗時顯示「連線失敗」與錯誤訊息，以及記錄檔的位置。
8. 按「確定」儲存。

左側清單中被選取的連線就是預設連線，對話框上方會顯示「目前選擇的預設資料庫連線是：」。清單上方的「複製」與「刪除」圖示作用在預設連線上。連線名不能重複，也不能空白。

### 4.2 從 Navicat、DBX 或 DBeaver 匯入連線

1. 在「資料庫連線設定」按下載圖示「匯入資料庫連線」。
2. 選擇來源：
   - 「選擇 Navicat 連線檔案 (.ncx)」：選擇從 Navicat 匯出的 `.ncx` 檔案。
   - 「選擇 DBX 連線檔案 (.json / dbx.db)」：選擇 DBX 的 `.json` 匯出檔或 `dbx.db` 資料檔。
   - 「選擇 DBeaver 連線檔案 (data-sources.json)」：選擇 DBeaver 工作區中的 `data-sources.json`。
3. 清單列出檔案中的連線，含「連線名」、「資料庫」、「主機」、「資料庫名」與「使用者名稱」。MyPD 不支援的資料庫類型會標示「（不支援）」，不能選取。
4. 點選一個連線。一次只能匯入一個。
5. 按「確定」。

Navicat 檔案中的密碼會一起匯入。DBX 的 `dbx.db` 密碼是加密的，`.json` 匯出檔通常不含密碼，匯入後請自行填寫。DBeaver 的帳號與密碼存在同一資料夾的 `credentials-config.json`，MyPD 讀得到這個檔案時會一起匯入，否則請自行填寫。

DBX 與 DBeaver 的連線檔都是 `.json`。MyPD 依檔案內容判斷格式，所以用哪一個按鈕選取都能正確讀取。兩種格式都不是的 `.json` 檔案會顯示「讀取失敗：」。

### 4.3 從資料庫逆向匯入專案

這個功能讀取資料庫中的資料表，並加入目前專案。

1. 確認已建立資料庫連線。沒有連線時，MyPD 會提示先到「資料庫」設定連線。
2. 按「匯入」→「從資料庫逆向匯入」→「從資料庫連線逆向解析」。
3. 在「選擇資料庫」步驟：
   - 在「請選擇需要解析的資料庫」選擇連線。
   - 連線是 MySQL、MariaDB、PostgreSQL 或 SQL Server 時，會多出「資料庫」下拉清單，列出伺服器上的資料庫，系統資料庫不會列出。讀取失敗時可以按「重新讀取」。url 沒有指定資料庫時會提示「連線未指定資料庫，將使用伺服器的預設資料庫，建議在此選擇。」
   - 在「邏輯名格式」選擇「全大寫」、「全小寫」或「不處理」。
4. 按「下一步」。MyPD 解析資料庫的資料表清單。
5. 在「選擇資料表」步驟勾選要加入的資料表。可以用「全選」，也可以在搜尋框依代碼或顯示名稱篩選。目前專案中已有的同名表會標示「選擇該資料表將會覆蓋系統中原有資料表」。
6. 在右側清單為資料表指定主題領域，或用「批次調整主題領域」一次指定。
7. 按「確定」。MyPD 分批讀取每張表的結構，畫面顯示處理進度。「每批解析」可以調整每批的表數，修改後從下一批生效。過程中可以「暫停」與「繼續」。
8. 讀取完成後確認結果。若有失敗的表，可以點「檢視出錯資訊」。
9. 按「確定」，資料表加入目前專案。

這個視窗可以調整大小：拖曳視窗右下角，資料表清單會跟著放大或縮小。

逆向完成後，專案的資料庫類型會跟著所選連線改變。

### 4.4 從資料庫逆向產生 PDM 檔案

這個功能把資料庫結構直接輸出成新的 `.pdm` 檔案，不必先放進專案。

1. 按「匯入」→「從資料庫逆向匯入」→「從資料庫逆向產生 PDM 檔案」。
2. 依 4.3 節的步驟 3 到 8 選擇連線、資料庫與資料表。
3. 按「確定」後，選擇 `.pdm` 檔案的存放位置與檔名。
4. MyPD 寫出 PDM 檔案，內含資料表、欄位、主鍵、索引與一張預設關係圖。
5. MyPD 接著詢問「加入目前專案」。按「確定」會把同一批資料表也加入目前專案，按「取消」則只產生 PDM 檔案。

### 4.5 備註的拆解與合併

資料庫的每張表與每個欄位只有一個備註，MyPD 則分成「顯示名稱」與「說明」兩個欄位。MyPD 用備註分隔符號在兩者之間轉換：

- 逆向時，MyPD 在第一個分隔符號處把備註拆成顯示名稱與說明。例如分隔符號是 `;` 時，`客戶編號;系統自動產生` 拆成顯示名稱 `客戶編號` 與說明 `系統自動產生`。
- 產生 DDL 時，MyPD 用分隔符號把顯示名稱與說明合併成備註。

「備註分隔符號」可以填多個字元，每個字元都是分隔符號。例如填 `,|` 再加一個空白，逗號、直線與空白都會拆開顯示名稱與說明：

| 備註 | 顯示名稱 | 說明 |
|------|----------|------|
| `客戶編號,系統自動產生` | `客戶編號` | `系統自動產生` |
| `客戶編號 系統自動產生` | `客戶編號` | `系統自動產生` |
| `客戶編號, 自動產生|不可修改` | `客戶編號` | `自動產生|不可修改` |

- 只有第一個分隔符號會拆開備註，後面的留在說明中；緊接在它後面的分隔符號與空白會一併略過。
- 產生 DDL 合併備註時，使用您填的第一個字元。空白在輸入欄中看不見，但會保留。把空白設為分隔符號後，含有空白的備註（例如 `User ID`）也會被拆開。

設定位置在「設定」→「系統參數」：

- 「拆解備註欄」：預設勾選。取消勾選後，逆向時整段備註都放進顯示名稱。
- 「備註分隔符號」：預設為 `;`，可以改成 `|`、`,` 或其他字元，也可以同時填多個字元。

這兩項存在專案檔案中，每個專案可以不同。

### 4.6 資料域寫入資料庫

「設定」→「系統參數」→「資料域寫入資料庫」預設不勾選。勾選後，建表 DDL 會記錄每個欄位的資料域：SQL Server 寫成欄位的擴充屬性 `Domain`，PostgreSQL 寫成真正的 `DOMAIN`。之後從 SQL Server 或 PostgreSQL 逆向時，MyPD 會讀回這些資訊，讓欄位重新對應到專案中的資料域。其他資料庫不支援這個功能。

## 5. PowerDesigner PDM 檔案

PDM 是 PowerDesigner 的實體資料模型檔案，格式為 XML。MyPD 有三種處理 PDM 的方式：直接開啟編輯、匯入到目前專案、把專案匯出為 PDM。這三種方式都不需要 Java。

### 5.1 直接開啟與編輯 PDM 檔案

1. 在首頁按「開啟」，選擇 `.pdm` 檔案。
2. MyPD 把 PDM 當成專案開啟。您可以照一般專案的方式編輯。
3. 按「儲存」。第一次儲存時，MyPD 顯示「寫回 PDM 檔案」的確認對話框。按「確定」後直接修改這個 PDM 檔案。

儲存 PDM 時要注意：

- 原始檔案在第一次被修改前，會複製一份成同目錄下的 `<檔名>.pdm.bak`。這個備份只建立一次，之後的儲存不會覆蓋它。
- 內容沒有改變時，MyPD 不會改動檔案。
- MyPD 先寫入暫存檔，再取代原檔，避免寫到一半中斷而損壞檔案。
- 自動儲存不會寫回 PDM 檔案，只有您自己按「儲存」才會寫回。`.back_` 快照也不適用於 PDM 檔案。

### 5.2 寫回 PDM 的內容

MyPD 只改寫專案與 PDM 檔案之間不同的部分，檔案中的其他內容保持原樣。

| 會寫回 PDM 檔案 | 不會寫回 PDM 檔案 |
|-----------------|-------------------|
| 資料表、欄位、欄位的資料域 | 資料字典 |
| 主鍵（含約束名稱）、替代鍵、索引 | 多表透視 |
| 資料域，含預設值、不為空與備註 | 邏輯實體 |
| 參照（關聯線），含基數、多欄位關聯與更新、刪除規則 | 關係圖上的形狀、註解與心智圖 |
| 預存程序與 PDM 中的檢視表（在 MyPD 中是資料庫物件） | 「設定」中的專案層級設定 |
| 資料表在關係圖中的位置，以及新增的關係圖 | 版本管理的版本 |
| 資料表的擁有者、預估資料列數、欄位的擴充屬性值 | |

PDM 中原有符號的外觀與大小維持檔案中的樣子。關係圖中的資料表符號被移除時，對應的參照仍保留，除非您在 MyPD 中刪除了該關聯線。

儲存 PDM 時的確認對話框文字仍寫著關係線與關係圖版面配置不會寫入，這段文字比目前的實作舊，以上表為準。若需要保留右欄的內容，請用「另存為」存成 `.pdma.json` 專案檔案。

### 5.3 從 PDM 檔案匯入到目前專案

1. 開啟要匯入資料的專案。
2. 按「匯入」→「從其他模型檔案中匯入」→「從PowerDesigner檔案」，選擇 `.pdm` 檔案。
3. 清單列出 PDM 中的資料表，並依 PDM 的套件分組。勾選要匯入的資料表，並指定主題領域。
4. 按「確定」。

匯入時的規則：

- 資料表、資料域、參照與關係圖會一起匯入。欄位仍對應到資料域，表與表之間的關聯也保留。
- 只匯入勾選的資料表。指向未勾選資料表的參照不會匯入。
- 專案已有同名資料表時，以 PDM 的內容取代，但保留專案原本的識別碼。
- 專案已有同程式碼但型別不同的資料域時，專案的資料域保留，不與 PDM 的資料域合併。
- 同一個 PDM 檔案匯入兩次，第二次不會再產生重複的內容。
- 專案的預設資料庫不會改變。
- PDM 中的預存程序與檢視表，會成為專案的資料庫物件。

### 5.4 把專案匯出為 PDM

1. 按「匯出」→「匯出文件」→「匯出為PowerDesigner檔案(.pdm)」。
2. 選擇存放位置與檔名，按儲存。

專案曾經從某個 PDM 檔案匯入資料時，MyPD 會記住那個檔案的內容，並把專案寫到那份內容上。PDM 中 MyPD 沒有顯示的部分，例如擴充屬性與關係圖的外觀，都會保留。專案沒有匯入過 PDM 時，MyPD 產生全新的 PDM 檔案。這時若專案沒有關係圖，資料表會以格狀排列在一張預設關係圖上。

專案只記住第一個匯入的 PDM 檔案。再次匯入同名的 PDM 檔案時，改記住較新的那份。

## 6. DDL 與程式碼

### 6.1 預覽資料表的 DDL

1. 開啟資料表，選擇「資料庫程式碼」頁籤。
2. 上方的頁籤列出每一種資料庫，預設選取專案的預設資料庫。
3. 左側選擇要看的語句，例如「建立資料表程式碼」或「建立索引程式碼」。

下方的「模型資料」按鈕顯示產生 DDL 用的資料，「編輯程式碼範本」可以修改這種資料庫的 DDL 範本。DDL 的語句分隔符號由「設定」→「系統參數」→「SQL分隔符號」決定，預設為 `;`。

### 6.2 匯出 DDL

1. 按「匯出」→「匯出SQL」→「匯出資料表結構DDL」。
2. 在「資料庫」選擇資料庫類型。
3. 在「匯出資料表/多表透視」按右側的三點圖示，選擇要匯出的物件。沒有選擇時匯出全部。
4. 在「匯出內容」選擇「全部」，或選「自訂」後在「自訂匯出內容」勾選「建表/多表透視陳述式」與「建索引陳述式」。
5. 專案中有資料庫物件時，可以勾選「包含資料庫物件」。
6. 按「產生DDL」，右側顯示產生的 SQL。您可以在右側直接修改。
7. 按「匯出」，MyPD 產生名為 `<專案名>-DDL-<時間>.sql` 的檔案。

### 6.3 程式碼產生器與範本

「程式碼產生器」頁籤列出程式碼範本，內建 Java、MyBatis、MyBatis-Plus、C#、Go、Rust 等語言。

1. 開啟資料表，選擇「程式碼」頁籤。
2. 上方頁籤選擇語言，左側選擇要看的檔案，右側顯示產生的程式碼。
3. 要把程式碼寫成檔案，按「路徑及變數」設定儲存位置、nameSpace、codeRoot 與檔案對映，再按「產生」或「確定並產生」。

範本使用 doT.js 語法。在範本編輯畫面中可以參考「dot.js語法介紹」。

### 6.4 版本管理與增量 DDL

版本管理記錄模型在不同時間點的狀態，並產生兩個版本之間的增量 DDL。以唯讀模式開啟的專案看不到這個頁籤。範本專案必須先另存成專案檔案才能使用。

1. 選擇左側的「版本管理」頁籤，再選「模型版本」。
2. 第一次使用時點「點選初始化基線版本」，填寫「版本名」與「版本說明」，建立基線。
3. 修改模型後，清單上方會顯示「有了新變化」。點「記錄新版本」，填寫版本名與說明，建立新版本。
4. 點清單中的版本。右側顯示這個版本相對於前一版的增量 DDL，資料庫類型為專案的預設資料庫。
5. 按「匯出」把增量 DDL 存成 `.sql` 檔案。按「模型資料」可以檢視這次變更的明細。

版本存在專案檔案旁邊的 `.version_<專案名>` 資料夾。只有最新的版本可以刪除。版本名不能重複，也不能空白。

「版本管理」中的「資料庫比較」把模型與資料庫連線的實際結構比較，並產生「模型相對資料庫，增量DDL」，這個功能需要 Java。
