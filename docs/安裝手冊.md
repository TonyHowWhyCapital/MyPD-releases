# MyPD 安裝手冊

適用版本：MyPD 1.2.4（macOS 與 Windows）。

本手冊說明如何安裝 MyPD、設定 Java，以及第一次啟動時會遇到的系統警告。安裝完成後的操作請看 [操作手冊](操作手冊.md)，測試範圍與問題回報方式請看 [測試說明](測試說明.md)。

## 1. 選擇與下載安裝檔

### 1.1 選擇安裝檔

| 您的電腦 | 安裝檔 |
|----------|--------|
| Mac，Apple 晶片（M1 之後的機型） | `MyPD-mac_arm64_v1.2.4.dmg` |
| Windows 10 或 11（64 位元） | `MyPD-win_x64_v1.2.4.exe` |

Mac 版只支援 Apple 晶片，不提供 Intel 處理器的版本。不確定 Mac 的晶片時，請點螢幕左上角的蘋果選單，選「關於這台 Mac」：「晶片」顯示 Apple M 系列才能安裝。

Windows 安裝檔是 64 位元程式，不能安裝在 32 位元的 Windows 上。不確定時，請開啟「設定」→「系統」→「系統資訊」（Windows 10 為「關於」），查看「系統類型」。顯示「64 位元作業系統」才能安裝。

### 1.2 下載

安裝檔放在 GitHub 的 Releases 頁面：<https://github.com/TonyHowWhyCapital/MyPD-releases/releases>。在該版本的「Assets」區塊點檔名下載。

下載時可能遇到下列狀況：

| 狀況 | 原因 | 處理方式 |
|------|------|----------|
| 頁面顯示 404（Page not found） | 這個版本庫不公開，瀏覽器沒有登入有權限的 GitHub 帳號 | 登入 GitHub 後重新整理。帳號沒有權限時，請向測試負責人申請，或請對方直接提供安裝檔 |
| Edge 顯示「不常下載」並停住下載 | 安裝檔沒有程式碼簽章 | 把滑鼠移到該筆下載上，點「…」→「保留」→「顯示更多」→「仍要保留」 |
| Chrome 顯示檔案可能有危險 | 同上 | 在下載清單中點該筆下載，選「保留」或「仍要下載」 |
| 下載後檔案被防毒軟體移除 | 公司的防毒軟體攔下沒有簽章的程式 | 請資訊人員把安裝檔加入允許清單 |

要確認下載的檔案完整，可以比對 Releases 頁面列出的 SHA-256：

- macOS：在終端機執行 `shasum -a 256 <檔案路徑>`。
- Windows：在命令提示字元執行 `certutil -hashfile <檔案路徑> SHA256`。

## 2. 系統需求

| 項目 | 需求 |
|------|------|
| 作業系統 | macOS 11 以上，或 64 位元的 Windows 10 以上 |
| 磁碟空間 | 安裝後約 350 MB |
| 網路 | 不需要。只有新版本檢查會連到 GitHub，可以關閉，請看第 8 節 |
| Java | 只有連線資料庫等功能需要，請看第 5 節 |

這一版安裝檔沒有經過 Apple 公證，也沒有 Windows 的程式碼簽章。第一次開啟時，系統會顯示安全性警告。這是正常現象，請依第 3、4 節各步驟的說明放行。

## 3. 在 macOS 安裝

### 3.1 安裝

1. 連按兩下 `.dmg` 檔案。
2. 在開啟的視窗中，把 MyPD 圖示拖到「應用程式」資料夾。
   - 系統詢問是否取代舊版時，請先結束執行中的 MyPD，再選「取代」。
3. 退出掛載的 MyPD 磁碟映像。

請不要直接在磁碟映像的視窗裡開啟 MyPD。一定要先拖到「應用程式」資料夾，否則後面的放行步驟不會生效。

### 3.2 第一次開啟

macOS 會擋下沒有公證的程式，只有第一次開啟需要放行。請依您看到的訊息處理：

**狀況一：顯示「無法打開 MyPD，因為 Apple 無法驗證」**

macOS 15 以上：

1. 在警告視窗按「完成」。請不要按「丟到垃圾桶」。
2. 開啟「系統設定」→「隱私權與安全性」。
3. 捲到「安全性」區塊，在 MyPD 被阻擋的訊息旁按「強制打開」（英文介面為 Open Anyway）。
4. 輸入 Mac 的登入密碼，再按一次「強制打開」。

「強制打開」按鈕只在您嘗試開啟 MyPD 之後的大約一小時內出現。沒看到時，請回到「應用程式」資料夾再連按兩下 MyPD 一次，然後重新整理這個設定頁面。

macOS 14 以下：

1. 在「應用程式」資料夾的 MyPD 上按右鍵（或按住 Control 點一下），選「打開」。
2. 在警告對話框按「打開」。

**狀況二：顯示 MyPD「已損毀，無法打開。您應該將其丟到垃圾桶」**

程式並沒有損毀。這是 macOS 對下載來的未公證程式顯示的訊息。請按「取消」，開啟「終端機」，執行下列指令後再開啟 MyPD：

```bash
xattr -dr com.apple.quarantine /Applications/MyPD.app
```

指令執行後沒有任何輸出就表示成功。狀況一的步驟無法放行時，也可以直接用這個指令。

**狀況三：顯示「無法打開此應用程式」或要求安裝 Rosetta**

安裝檔與晶片不相符。請把「應用程式」資料夾中的 MyPD 丟到垃圾桶，依第 1.1 節重新選擇安裝檔。

**狀況四：公司的 Mac 沒有「強制打開」按鈕，終端機指令也無效**

這台 Mac 受公司的裝置管理原則限制。請聯絡資訊人員放行 MyPD。

## 4. 在 Windows 安裝

1. 連按兩下 `MyPD-win_x64_v1.2.4.exe`。
   - 出現「Windows 已保護您的電腦」的藍色視窗時，點「其他資訊」，再按下方出現的「仍要執行」。這個視窗一開始只有「不要執行」按鈕，一定要先點「其他資訊」。
   - 顯示「需要 64 位元 Windows 系統」時，表示這台電腦是 32 位元的 Windows，無法安裝這一版。
   - 連按兩下後沒有任何反應，或檔案消失時，是防毒軟體攔下了安裝檔。請聯絡資訊人員把安裝檔加入允許清單。
2. 選擇安裝對象。
   - 「僅為我安裝」不需要系統管理員權限，建議選這一項。
   - 「為使用這台電腦的任何人安裝」會要求系統管理員權限。沒有權限時請改選「僅為我安裝」。
3. 視需要變更安裝位置，按「安裝」。
   - 顯示 MyPD 正在執行、無法關閉時，請先結束 MyPD，再按「重試」。
   - 電腦上裝過舊的 32 位元版本時，請先依第 8 節移除舊版，再安裝這一版。專案檔案與設定不受影響。
4. 安裝完成後，從桌面捷徑或開始功能表開啟 MyPD。
   - 第一次使用資料庫連線功能時，Windows 防火牆可能詢問是否允許 Java 連線網路。要連線資料庫請按「允許存取」。

## 5. 設定 Java

### 5.1 哪些功能需要 Java

MyPD 的建模、關係圖、PDM 檔案、DDL 匯出、報表等功能都不需要 Java。下列功能透過內附的 Java 引擎執行，電腦上必須有 Java：

- 資料庫連線的「測試」。
- 從資料庫逆向匯入，以及從資料庫逆向產生 PDM 檔案。
- 與資料庫比較（「模型比較與合併」的「資料庫」一側、「版本管理」的「資料庫比較」）。
- 從 Excel 匯入、匯出 Excel、匯出 Word（「匯出」選單中的「匯出為WORD文件」）。
- 從 DDL 檔案逆向解析。

用不到這些功能時，可以略過本節。

### 5.2 安裝 Java

建議安裝 Java 17。MyPD 的開發與驗證都在 Java 17 上進行。Java 引擎以 Java 8 的格式編譯，所以 Java 8 以上的版本理論上都能執行，但其他版本沒有驗證過。

電腦上已經有 Java 時不必重裝。請開啟終端機（macOS）或命令提示字元（Windows），執行 `java -version` 檢查。

還沒有 Java 時，請安裝任何一種 JDK 17，例如 Eclipse Temurin 17：

- macOS：使用 `.pkg` 安裝檔。它會把 JDK 裝在 `/Library/Java/JavaVirtualMachines`，MyPD 不需要其他設定就能找到。
- Windows：使用 `.msi` 安裝檔，安裝時保留「加入 PATH」的選項。

用 Homebrew、SDKMAN 或解壓縮方式安裝的 JDK，MyPD 通常找不到，請依 5.3 節指定 Java 的位置。

### 5.3 在 MyPD 中確認或指定 Java

1. 開啟 MyPD，再開啟任一專案。沒有專案時，可以在首頁的「參考範本」開啟一個範例。
2. 按工具列的「設定」，選擇「系統參數」頁籤。
3. 「JAVA_HOME」留白時，MyPD 使用系統中的 `java` 指令。按右側的「測試」。
4. 測試成功時，對話框會顯示 Java 的版本，表示設定完成。
5. 測試失敗時，在「JAVA_HOME」填入 JDK 的安裝目錄，或按輸入框右側的「選擇目錄」圖示選擇資料夾，再按「測試」。
6. 按「確定」儲存。

「JAVA_HOME」要填的是含有 `bin` 資料夾的那一層目錄：

| 系統 | 如何找到 | 範例 |
|------|----------|------|
| macOS | 在終端機執行 `/usr/libexec/java_home` | `/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home` |
| Windows | 在命令提示字元執行 `where java`，取 `\bin\java.exe` 之前的部分 | `C:\Program Files\Eclipse Adoptium\jdk-17.0.13.11-hotspot` |

這個設定存在這台電腦上，所有專案共用。

### 5.4 內附的資料庫驅動程式

Java 引擎內附下列資料庫的 JDBC 驅動程式，不需要另外下載：

| 資料庫 | 內附的驅動程式 |
|--------|----------------|
| MySQL | mysql-connector-java 8.0.26 |
| Oracle | ojdbc8 21.3 |
| SQL Server | mssql-jdbc 6.2.2（jre8） |
| PostgreSQL | postgresql 42.2.23 |
| SQLite | sqlite-jdbc 3.36 |
| DB2、達夢、人大金倉、瀚高、openGauss、GBase、MaxCompute | 各自的驅動程式 |

連線其他資料庫，或需要較新版本的驅動程式時，請在「資料庫連線設定」的「自訂驅動程式」選擇該驅動程式的 `.jar` 檔案。連線 SQL Server 失敗時，請先試著改用與您的 Java 版本相符的 mssql-jdbc 驅動程式。

## 6. 安裝後的檢查

請依序確認下列項目，每一項都正常就表示安裝完成：

1. MyPD 可以開啟，並顯示首頁。
2. 在首頁的「參考範本」開啟一個範例專案，左側的模型樹列出資料表。
3. 連按兩下一張資料表，右側開啟欄位清單。
4. 「設定」→「系統參數」→「JAVA_HOME」的「測試」顯示 Java 版本（需要資料庫功能時）。
5. 按工具列的「資料庫」，建立一個連線並按「測試」，顯示「連線成功」（需要資料庫功能時）。

## 7. MyPD 存放資料的位置

| 內容 | macOS | Windows |
|------|-------|---------|
| 程式 | `/Applications/MyPD.app` | 安裝時選擇的位置，預設為 `%LOCALAPPDATA%\Programs\MyPD` |
| 這台電腦的設定與最近開啟清單 | `~/Library/Application Support/MyPD` | `%APPDATA%\MyPD` |
| 專案檔案與備份 | 您建立專案時選擇的資料夾 | 同左 |

專案檔案旁邊會出現 `.back_<專案名>` 與 `.version_<專案名>` 資料夾，分別存放儲存時的快照與版本管理的版本，請不要刪除。詳細說明請看 [操作手冊](操作手冊.md) 第 1 節。

## 8. 更新與移除

**更新。** 收到新版安裝檔時，先關閉 MyPD，再照第 3 或第 4 節重新安裝，覆蓋舊版即可。設定與專案檔案不受影響。

**新版本檢查。** MyPD 啟動時會向 GitHub 查詢最新版本號。有新版時，首頁左下角顯示「下載新版本」連結，點它會用瀏覽器開啟下載頁面。MyPD 不會自動下載或安裝。

- 要立刻檢查，請點首頁左下角的「檢查更新」。
- 不想讓程式連線時，取消勾選「啟動時自動檢查」。
- 電腦連不到 GitHub 時，自動檢查不會顯示任何訊息；手動檢查會顯示「無法取得版本資訊」。這不影響其他功能，請改向測試負責人確認是否有新版。
- 查詢時不傳送任何專案或使用者資料。

**移除。**

- macOS：把「應用程式」資料夾中的 MyPD 拖到垃圾桶。
- Windows：到「設定」→「應用程式」→「已安裝的應用程式」，找到 MyPD 後選「解除安裝」。

移除程式不會刪除專案檔案。要一併清除這台電腦上的設定，請刪除第 7 節表格中的設定資料夾。

## 9. 安裝問題排除

| 狀況 | 處理方式 |
|------|----------|
| 下載頁面顯示 404，或瀏覽器擋下下載 | 請看第 1.2 節 |
| macOS 顯示無法驗證 MyPD，沒有「打開」按鈕 | 請看 3.2 節的狀況一 |
| macOS 顯示 MyPD 已損毀 | 請看 3.2 節的狀況二，執行 `xattr` 指令 |
| Mac 顯示無法打開此應用程式，或要求安裝 Rosetta | 安裝檔與晶片不相符，請看 3.2 節的狀況三 |
| Windows 顯示「Windows 已保護您的電腦」 | 點「其他資訊」，再按「仍要執行」，請看第 4 節步驟 1 |
| Windows 安裝程式顯示「需要 64 位元 Windows 系統」 | 這台電腦是 32 位元的 Windows，無法安裝這一版 |
| Windows 安裝檔按了沒有反應，或檔案消失 | 防毒軟體攔下了安裝檔，請聯絡資訊人員加入允許清單 |
| Windows 安裝時要求系統管理員權限 | 在安裝對象改選「僅為我安裝」 |
| 出現以「未偵測到JDK」開頭的訊息 | 依第 5 節安裝 Java 並指定「JAVA_HOME」 |
| 「JAVA_HOME」的「測試」失敗 | 確認填入的目錄下有 `bin/java`（Windows 為 `bin\java.exe`） |
| 連線「測試」失敗 | 對話框會顯示錯誤訊息與記錄檔資料夾的位置。請先確認 url、帳號、密碼與網路，再把錯誤訊息回報給測試負責人 |
| 逆向大型資料庫時顯示記憶體不足 | 到「設定」→「系統參數」→「JVM參數」，把 `-Xmx1024m` 改大，例如 `-Xmx2048m` |
