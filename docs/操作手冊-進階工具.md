# MyPD 操作手冊：進階工具與參考

適用版本：MyPD 1.2.3（macOS 與 Windows）。

這是操作手冊的第二份，說明快捷工具、其他匯入與匯出、表格共通功能、設定、快捷鍵與常見問題。基本概念、介面與建模流程請看 [MyPD 操作手冊](操作手冊.md)。安裝與 Java 設定請看 [安裝手冊](安裝手冊.md)。

本手冊中以「」標示的文字，是 MyPD 在繁體中文介面上顯示的名稱。箭頭表示選單的層級，例如「快捷工具」→「輸出」→「報表」。

## 7. 快捷工具

工具列的「快捷工具」把工具分成五組：

| 群組 | 工具 |
|------|------|
| 「比較與分析」 | 「模型比較資料庫」、「模型內自訂表比較」、「模型比較與合併」、「影響分析」 |
| 「編輯與管理」 | 「模型清單編輯」、「資料表範本」、「資料庫物件」、「大小寫轉換」 |
| 「輸出」 | 「報表」 |
| 「測試資料」 | 「產生測試資料」、「測試資料規則」 |
| 「顯示」 | 「夜間模式」或「白天模式」 |

本節的工具都在對話框中操作。工具中的「儲存」只把修改寫進目前開啟的專案，要寫進磁碟，請再按工具列的「儲存」或 Cmd+S、Ctrl+S。工具中有尚未儲存的修改時，關閉或切換對象前 MyPD 會先詢問是否「放棄未儲存的修改？」。

### 7.1 影響分析

影響分析在您刪除資料表、刪除欄位或修改欄位型別之前，列出會受影響的物件。

1. 按「快捷工具」→「比較與分析」→「影響分析」。
2. 在「新增影響分析」區塊的「操作型別」選擇「刪除資料表」、「刪除欄位」或「修改欄位型別」。
3. 選擇「資料表」。若操作與欄位有關，再選擇「欄位」。
4. 若選「修改欄位型別」，填寫「新資料型別」、「長度」與「小數位」。
5. 按「預覽影響」。

結果表格列出每個受影響的物件，含「物件型別」、「物件」、「所屬」、「原因」、「嚴重程度」與「說明」，表格上方顯示「破壞」、「變更」、「提示」三種嚴重程度的數量。受影響的物件包括外鍵參照、多表透視、索引、關係圖中的節點與關聯線、主題領域、資料庫物件，以及使用相同資料域的欄位。

要保留這次分析：

1. 在結果下方的「分析名稱」輸入名稱。
2. 按「儲存為影響分析」。

儲存的分析列在左側「已儲存的影響分析」，點一下就能重新檢視，按「刪除」移除。這些分析存在專案中，報表也可以輸出它們。

影響分析只預覽，不會真的刪除或修改任何東西。

### 7.2 模型比較與合併

這個工具比較兩個模型，列出差異，並產生 ALTER 指令碼或把差異合併到目前專案。

1. 按「快捷工具」→「比較與分析」→「模型比較與合併」。
2. 在「模型 A」與「模型 B」各選一個來源：
   - 「目前專案」：目前開啟的專案，包含尚未儲存的修改。
   - 「專案檔案」：按「選擇檔案」選擇另一個 `.pdma.json` 專案檔案。
   - 「資料庫」：選擇一個資料庫連線。MyPD 讀取該資料庫目前的結構，需要 Java。
3. 在「被修改的一側(目標)」選擇「修改 A，使其與 B 一致」或「修改 B，使其與 A 一致」。
4. 按「比較」。

差異以樹狀列出，依「表」與「資料庫物件」分類，再細分為「新增」、「刪除」、「修改」，以及「基本資訊」、「欄位」、「索引」。兩邊沒有差異時顯示「兩個模型沒有差異」。

處理差異：

1. 勾選要處理的差異，或勾選「全選」。
2. 選擇處理方式：
   - 「產生 ALTER 指令碼」：顯示把目標改成與來源一致所需的 SQL。
   - 「合併到目前專案」：把勾選的差異套用到目前專案。只有目標一側是「目前專案」時才能使用。合併可能刪除資料表或欄位，MyPD 會先確認。
3. 合併後，畫面顯示「已合併，請儲存專案」。請按「儲存」寫入磁碟。

**執行到資料庫。** 目標一側是「資料庫」時，ALTER 指令碼視窗多一個「執行到資料庫」按鈕，可以把指令碼直接套用到那個資料庫。需要 Java。

1. 勾選差異，按「產生 ALTER 指令碼」。
2. 視需要在視窗中修改指令碼。執行的是視窗裡目前的文字，包含您的修改。
3. 按「執行到資料庫」。MyPD 把指令碼切成一條一條陳述式，先顯示確認視窗，列出：
   - 連線名稱、伺服器與資料庫。不會顯示帳號與密碼。
   - 將執行的陳述式數量。
   - 這個資料庫失敗時能不能全部還原，說明見下表。
   - 會刪除資料表、欄位、索引或資料的陳述式（`DROP`、`TRUNCATE`），以紅字逐條列出。
4. 確認後按「確定」。執行時畫面顯示「正在執行」與進度。
5. 全部成功時，畫面顯示已執行的陳述式數量，指令碼視窗關閉，MyPD 重新比較，差異清單會反映資料庫目前的結構。

有陳述式失敗時，執行會停在那一條。錯誤視窗顯示是第幾條失敗、那條 SQL、資料庫的錯誤訊息，以及「已全部還原」或「前 n 條陳述式已生效」。關閉錯誤視窗後，MyPD 也會重新比較。指令碼視窗不會關閉，您可以修改後再執行。

失敗時的結果依資料庫而不同：

| 資料庫 | 失敗時 |
|--------|--------|
| PostgreSQL、SQL Server、SQLite | 所有陳述式在同一個交易中執行，任一條失敗就全部還原，資料庫不會有任何變更 |
| MySQL、Oracle 與其他資料庫 | 這些資料庫的 DDL 執行後立即生效。失敗前已執行的陳述式不會還原，請依錯誤視窗的說明自行處理 |

**`DROP` 與 `TRUNCATE` 刪除的資料無法復原。** 刪除欄位或資料表時，裡面的資料也會一併刪除。在模型中改了資料表代碼時，比較結果是刪除舊表、新增新表，執行後舊表的資料會遺失。MySQL、PostgreSQL 與 SQL Server 的指令碼新增資料表前會先刪除同名的資料表，資料庫裡已經有這張表時，原有的資料同樣會遺失。執行前請先備份資料庫。

**請先在測試環境執行。** 確認指令碼的結果正確後，再對正式的資料庫執行。

切分陳述式的規則：以分號 `;` 分隔，或以單獨一行的 `/`、`GO` 分隔。字串、註解與加上引號的名稱中的分號不會切開。預存程序、函式、觸發程序與套件從開頭到最外層的 `END` 視為一條。Oracle 的 PL/SQL 區塊建議在 `END;` 下一行加上 `/`。

### 7.3 模型清單編輯

模型清單編輯以表格一次檢視與修改整個專案，適合大量修改欄位名稱、型別或資料域。

1. 按「快捷工具」→「編輯與管理」→「模型清單編輯」。
2. 在上方切換「資料表」、「欄位」或「資料域」。
3. 直接在儲存格中修改。上方的「搜尋」框可以篩選列。
4. 修改後畫面顯示「未儲存」。按「儲存」把修改寫入專案，或按「放棄修改」回到修改前。

三個分頁的內容：

| 分頁 | 欄位 | 可做的事 |
|------|------|----------|
| 「資料表」 | 「代碼」、「名稱」、「說明」、「欄位數」 | 修改名稱與說明，刪除資料表 |
| 「欄位」 | 「所屬表」、「代碼」、「名稱」、「資料域」、「型別」、「長度」、「小數」、「主鍵」、「不可為空」、「自動遞增」等 | 跨所有資料表修改欄位，新增或刪除欄位 |
| 「資料域」 | 「代碼」、「名稱」、「型別」、「長度」、「小數」 | 修改、新增或刪除資料域 |

使用說明：

- 在「欄位」分頁，按「欄位設定」選擇要顯示的欄位。要新增欄位，先在旁邊的下拉清單選資料表，再按「新增欄位」。
- 在「資料域」儲存格選「＋ 新增資料域…」，可以當場建立資料域並套用到該欄位。選「（不使用資料域）」則取消套用。
- 在「資料域」分頁按「新增資料域」新增一列。仍被欄位使用的資料域不能刪除，MyPD 會顯示「該資料域仍被欄位參照，無法刪除。」
- 刪除資料表時，MyPD 同時處理它在關聯、索引、關係圖與主題領域中的引用。
- 點表頭排序，依次點多個表頭可以多欄排序，點「清除排序」恢復。拖曳表頭可以調整欄位順序，點「還原欄位順序」恢復。「最適欄寬」與「還原欄寬」調整欄寬。

按「儲存」只寫入目前開啟的專案。請再按工具列的「儲存」寫入磁碟。

### 7.4 資料庫物件

資料庫物件是資料表以外、要隨 DDL 一起建立的物件。

1. 按「快捷工具」→「編輯與管理」→「資料庫物件」。
2. 左欄依類型篩選：「全部」、「觸發程序」、「預存程序/函式」、「檢視表(SQL)」、「序列」、「分割區」、「資料表空間」、「同義字」、「權限」。
3. 按「新增」，在「型別」選擇物件類型。
4. 填寫「代碼」、「名稱」、「備註」，視類型選擇「關聯表」並填寫各類型專屬的屬性。觸發程序與預存程序還需要在「陳述式內容」輸入 SQL 本體。
5. 若要完全自己寫建立語句，填寫「自訂DDL（非空時替換產生的建立陳述式）」。
6. 右側選擇「資料庫」，即可預覽該資料庫的 DDL。
7. 按「儲存」。

同一類型中的程式碼不能重複。中欄上方的搜尋框可以依程式碼或名稱篩選。

匯出 DDL 時，「匯出資料表結構DDL」對話框會出現「包含資料庫物件」，勾選後一起匯出。從 PDM 檔案開啟或匯入時，PDM 中的預存程序與檢視表會成為資料庫物件。

### 7.5 報表與報表範本設計

報表依範本從一個或多個模型產生文件。報表輸出不需要 Java。

開啟報表工具：按「快捷工具」→「輸出」→「報表」。視窗分成三欄：左欄是「報告範本」清單，中欄是「範本設計」，右欄是「產生報告」。

專案還沒有範本時，清單顯示內建範本，並提示「尚未儲存範本，目前顯示內建範本，儲存或修改後將寫入專案」。

**範本的兩種報告種類。**

- 「文件報告」：由多個章節組成的文件。
- 「清單報告」：只有一個章節，且該章節輸出一張表格。只有清單報告可以輸出 CSV。

**建立與編輯範本。**

1. 在左欄按「新增文件範本」或「新增清單範本」。也可以在現有範本上按「複製」。
2. 在中欄填寫「範本名稱」。
3. 在「章節」選擇章節種類，按「新增章節」。可用的章節有：文字、目錄、模型概要、資料表清單、資料表詳情、欄位清單、索引清單、檢視表清單、資料字典、資料域清單、關係清單、資料庫物件、影響分析。
4. 視需要填寫「章節標題」。留空時使用章節種類的名稱。
5. 表格類章節可以點預覽或「版面設計」，開啟「欄位版面設計」。
6. 按「儲存範本」。

章節可以拖曳調整順序，也可以「收合」、「展開」或「移除」。

**文件版面。** 範本名稱下方的「文件版面」決定報告是否像正式文件一樣排版：

| 選項 | 效果 |
|------|------|
| 「封面」 | 第一頁是封面，顯示報告名稱、「副標題」、「單位」、「作者」、「版本」與日期。封面不印頁首與頁碼 |
| 「封面 Logo」、「封面底圖」 | 按「選擇圖片」放入 PNG 或 JPG（2MB 以內）。Logo 在標題上方，底圖鋪滿整頁。圖片隨範本儲存在專案檔中 |
| 「頁首」 | 每頁上方顯示報告名稱，右側顯示「單位」，沒有填寫時顯示日期 |
| 「頁碼」 | 可選「不顯示」、「1」、「1 / 10」或「第 1 頁，共 10 頁」。有封面時從封面的下一頁算起 |
| 「章節編號」 | 章節標題前加上 1、1.1、1.2 這樣的編號 |
| 「目錄頁次」 | 目錄的每一條附上頁碼。範本要有「目錄」章節 |
| 「橫向」 | 紙張改為 A4 橫向，適合欄位多的表格 |

文件報告預設開啟封面、頁首、頁碼、章節編號與目錄頁次；清單報告預設全部關閉。

「頁首」、「頁碼」與「目錄頁次」只用在 Word 文件。「封面」與「章節編號」適用於 Word、網頁與 Markdown。目錄的每一條都會連到對應的章節。

開啟匯出的 Word 文件時，Word 會詢問是否更新功能變數，請選擇「是」，目錄才會填入頁次。如果頁次不正確，在目錄上按右鍵，選擇「更新功能變數」。

**欄位版面設計。** 在「欄位版面設計」中：

- 在上方勾選「顯示欄位」，決定表格有哪些欄。
- 點選抬頭或內容，在右側編輯屬性：「顯示名稱」、「順序」、「寬度」、「對齊」、「字型大小」、「字型」、「文字顏色」、「底色」與粗體、斜體、底線。
- 拖曳抬頭調整欄的順序，拖曳分隔線調整寬度。
- 「字型與顏色套用到所有欄位」把目前的樣式套用到全部欄。
- Cmd+Z 或 Ctrl+Z 復原，Cmd+Y 或 Ctrl+Y 重做。

**產生報告。**

1. 在右欄的「包含的模型」中，「目前專案」一定會包含。要合併其他專案，按「新增模型檔案」選擇 `.pdma.json` 檔案。
2. 在「輸出格式」選擇格式：

| 格式 | 保留的樣式 |
|------|------------|
| 「Word 文件 (.docx)」 | 欄寬、對齊、字型與顏色，以及全部的文件版面 |
| 「網頁 (.html)」 | 欄寬、對齊、字型與顏色 |
| 「Markdown (.md)」 | 只保留對齊 |
| 「CSV (.csv)」 | 純資料，只有清單報告可用 |

3. 按「預覽」檢視結果。Word 與網頁格式的預覽中可以拖曳抬頭分隔線調整欄寬，點對齊圖示切換對齊，儲存範本後保留。預覽只顯示前幾筆資料。
4. 按「匯出」，MyPD 以範本名稱產生檔案。

範本存在專案中，修改後請儲存專案。

### 7.6 資料表範本

資料表範本是一組預設欄位，例如每張表都要有的建立人、建立時間欄位。

建立範本：

1. 按「快捷工具」→「編輯與管理」→「資料表範本」。
2. 按「新增範本」。或在「選擇資料表」選一張現有的表，按「從已有表建立」，以那張表的欄位為起點。
3. 填寫「範本代碼」與「範本名稱」，視需要填寫「備註」。
4. 在「預設欄位」按「新增欄位」，填寫每個欄位的程式碼、名稱、「資料域」或「資料型別」、「長度」、「小數位」、「主鍵」與「不可為空」。
5. 按「儲存範本」。

範本代碼不能空白，也不能重複。同一個範本中的欄位代碼也不能重複。

使用範本：建立資料表時，在「建立方式」選「從範本建立」，再選範本。勾選「保持與範本的關聯」，這張表就會出現在範本的「關聯的資料表」清單中。

同步範本：修改範本後，按「同步關聯的表」。MyPD 先提示會覆蓋幾張關聯資料表的欄位，確認後才同步。

刪除範本時，關聯的資料表保留目前的欄位，只解除關聯。

### 7.7 其他工具

**模型比較資料庫。** 這個項目切換到「版本管理」頁籤的「資料庫比較」，比較模型與資料庫的實際結構。需要 Java。

**模型內自訂表比較。** 在同一個專案中，以「比較清單」比較指定的資料表。按「新增列」逐列選取要比較的表。「儲存比較清單」與「載入比較清單」把清單存成檔案或讀回來。按「掃描欄位差異」之後，「不一致」的表和欄位旁邊會寫出原因，左邊指檢查表，右邊指比較表。按「差異清單」可以把已掃描的差異列成一張表，比較表是調整前，檢查表是調整後。

**大小寫轉換。** 一次轉換整個專案的英文大小寫。對話框中可以分別為「表名」、「欄位名」、「索引名」與「資料型別」選擇「全部大寫」或「全部小寫」，按「確定」套用。

**操作歷史。** 工具列的「操作歷史」列出每次儲存時留下的快照，最新的在最上方。每一筆有四個操作：

- 「新視窗開啟」：在新視窗以唯讀模式開啟這份快照。
- 「詳細記錄」：顯示這份快照與前一份之間的變更。上方的差異表逐項列出變更，「調整前（上一版本）」欄是前一份快照的值，「調整後（本版本）」欄是這一份的值。下方是文字說明。
- 「還原」：用這份快照取代目前專案。這個操作會覆蓋目前專案的內容。恢復後請儲存專案。
- 「刪除」：刪除這份快照檔案。

### 7.8 產生測試資料

這個工具依資料表、欄位與外鍵關係產生測試資料，輸出成檔案或直接寫入資料庫。產生檔案不需要 Java；直接寫入資料庫、讀取資料庫現有的鍵值與「資料庫查詢」規則需要 Java 與資料庫連線。

開啟方式：按「快捷工具」→「測試資料」→「產生測試資料」。也可以在模型樹的資料表上按右鍵選「產生測試資料」，這樣開啟時會先勾選那些資料表。

視窗分成三個步驟，上方的步驟列可以點選切換，下方的「上一步」與「下一步」也可以切換。

**步驟 1「選擇資料表與筆數」**

1. 在左邊的清單勾選要產生資料的資料表。清單可以搜尋，也可以「全選」。
2. 右邊列出勾選的資料表，每張表可以設定：
   - 「筆數」：「固定筆數」，或「依上層筆數」（每筆上層資料產生幾筆）。沒有指定時使用「預設筆數」。
   - 「自動編號 / 起始值」：「程式產生編號」從起始值依序編號並寫入；「交給資料庫」輸出時略過這個欄位，由資料庫自己編號，此時其他資料表無法參照這些編號。
   - 「欄位規則」：顯示有幾個欄位有自己的規則，點選可以跳到步驟 2 檢視與修改。
3. 資料表有外鍵而上層資料表沒有勾選時，「狀態」欄會提示。您可以選「一併產生」上層資料表，或選「讀取資料庫現有的鍵值」，讓外鍵的值取自資料庫裡已經存在的資料。
4. 視需要調整「隨機種子」。「固定」時，同樣的設定每次產生同樣的資料，換一個數字就換一批資料；「每次不同」時，每次產生的資料都不一樣。

**步驟 2「欄位規則與預覽」**

左邊是要產生的資料表，中間是所選資料表的欄位，下方是「預覽前 N 筆」。

- 每個欄位顯示「資料型別」、「標記」（主鍵、外鍵、不可重複、自動編號、不可為 NULL）、「規則」與「NULL 比例」。
- 沒有指定規則的欄位是「自動」：依欄位的資料域或資料型別決定內容。
- 在「規則」欄可以為欄位選擇規則，或用「新增規則…」建立新的規則。
- 「NULL 比例」是這個欄位留空的百分比。主鍵與唯一索引的欄位不會留 NULL。
- 預覽中外鍵的值僅供參考，正式產生時會對應到實際的上層資料。規則用到檔案或資料庫時，按「重新讀取外部資料」更新預覽。

**步驟 3「輸出」**

可以同時勾選多種輸出，它們會得到完全相同的資料。

| 輸出 | 說明 |
|------|------|
| 「SQL 檔案（INSERT）」 | 依專案的資料庫類型產生 INSERT。可選「多筆合併成一條 INSERT」；SQL Server 可選「用 GO 分批」 |
| 「CSV 檔案」 | 每個資料表一個檔案，UTF-8 |
| 「Excel 活頁簿」 | 每個資料表一個工作表 |
| 「直接寫入資料庫」 | 會真的更改資料庫裡的資料，需要資料庫連線與 Java |

完整支援的資料庫是 SQL Server、MySQL、PostgreSQL 與 Oracle。專案是其他資料庫類型時輸出標準 SQL，尚未在該資料庫上驗證，使用前請先檢查。

按「產生」開始。要覆蓋現有的檔案時，MyPD 會先列出這些檔案請您確認。

**直接寫入資料庫的確認。** 選了「直接寫入資料庫」時，按「產生」後不會立刻寫入。MyPD 先顯示「寫入資料庫前請確認」，列出伺服器、資料庫，以及每張資料表「資料庫現有」與「將寫入」的筆數。請在這裡決定兩件事：

- 「資料表裡現有的資料」：「保留，接在後面寫入」或「先清除，再寫入」。選擇清除時，必須輸入資料庫名稱或連線名稱確認，刪除後無法還原。
- 「有資料寫入失敗時」：「全部復原」（只要有一筆失敗，這次寫入全部取消）或「略過失敗的資料，繼續寫入」。

確認後按「寫入資料庫」。資料庫裡沒有對應的資料表時無法寫入，請先用匯出 DDL 建立資料表。**請只對測試用的資料庫使用這個功能。**

完成後，視窗顯示各資料表的筆數、產生的檔案與耗時。有資料寫入失敗時，會列出失敗的筆數與原因。

**調整版面。** 步驟 1 的資料表清單、步驟 2 的三個區塊之間有分隔線，可以拖曳調整大小。大小記在這台電腦上，在分隔線上連按兩下恢復預設大小。

**測試資料規則**

按「快捷工具」→「測試資料」→「測試資料規則」管理規則。視窗有三個頁籤：

| 頁籤 | 內容 |
|------|------|
| 「專案規則」 | 儲存在專案檔案中。欄位和資料域參照的都是這裡的規則 |
| 「本機規則庫」 | 儲存在這台電腦上，每個專案都能取用；欄位要用時會先複製一份到專案 |
| 「資料域」 | 為資料域指定規則後，使用該資料域的欄位會自動套用；欄位自己指定的規則優先 |

規則可以「新增規則」、「複製一份」、「刪除」，也可以在專案與本機規則庫之間複製，或「匯入」、「匯出」成檔案。每條規則有「規則名稱」、「規則類型」、「NULL 比例」與「產生的值不重複」。規則類型如下：

| 規則類型 | 內容 |
|----------|------|
| 「自動」 | 依欄位的資料型別和長度自動決定內容 |
| 「流水號」 | 依次遞增的編號，可以加上前置文字、後置文字並補零 |
| 「數字範圍」 | 在最小值和最大值之間隨機取數 |
| 「日期範圍」 | 在起訖日期之間隨機取日期或時間 |
| 「隨機文字」 | 指定長度範圍和字元種類的隨機文字 |
| 「清單」 | 從自己列出的值裡挑選，可以設定權重 |
| 「格式」 | 依照格式逐字產生，例如車牌、產品編號 |
| 「資料字典」 | 從專案的資料字典取代碼或名稱 |
| 「內建資料」 | 接近真實的資料，分成台灣、英文與通用三組：姓名、手機號碼、地址、縣市、公司名稱、統一編號、身分證字號、電子郵件、網址等 |
| 「檔案」 | 從文字檔案或 CSV 檔案的某一欄取值 |
| 「資料庫查詢」 | 執行一條 SELECT，以結果的第一欄作為取值清單 |
| 「公式」 | 用同一筆資料的其他欄位計算，以 `[欄位代碼]` 參照其他欄位 |
| 「固定值」 | 每一筆都是同一個值 |

「檔案」規則的檔案在專案檔案所在的資料夾內時，可以用相對位置儲存，專案和檔案一起搬移後仍然找得到。

「資料庫查詢」規則只能使用一條 SELECT。編輯時 MyPD 會對照專案模型檢查查詢用到的資料表與欄位；按「檢查語法」會連線資料庫，由資料庫判斷語法是否正確，並取回前幾個值。這個檢查只會讀取，不會更改資料。查詢要到產生資料的時候才會真正執行。

## 9. 表格共通功能

資料表的欄位清單、模型清單編輯、匯入連線清單等表格，有一組共通的功能。表格上方或表頭的提示文字會說明可用的操作。

| 功能 | 操作 |
|------|------|
| 選擇顯示的欄 | 點「顯示欄位」，勾選或取消勾選欄。點「還原欄位」恢復預設 |
| 調整欄的順序 | 拖曳表頭到新的位置 |
| 排序 | 點表頭的排序符號，依序切換遞增、遞減、不排序。依次點多欄就是多欄排序，符號旁的數字是排序順位。點「清除排序」取消 |
| 調整欄寬 | 拖曳表頭右緣。在右緣連按兩下設為最適欄寬 |
| 全部最適欄寬 | 點「最適欄寬」。點「還原欄寬」恢復預設 |

排序後，正在編輯的列不會因為內容改變而跳走，直到您改變排序條件。下拉清單的寬度會跟著欄寬。欄的顯示、順序與欄寬記在這台電腦上，每個表格各自記住，不會寫進專案檔案。

資料表的欄位清單上方另有「匯出 CSV」與「匯出 Excel」，可以把欄位清單匯出成檔案。有選取的列時只匯出選取的列，沒有選取時匯出全部。

### 10.5 專案內容與語言

專案建立時帶入的內建設定（資料域、預設欄位、基本資料型別、「UI建議」選項、欄位標題、命名規範與程式碼範本）存在專案檔案中。開啟專案或切換語言時，仍是內建預設值的名稱會換成目前語言的名稱；您自己改過的名稱不會變動。

介面是繁體中文時，MyPD 還會把專案中以簡體中文書寫的模型內容轉成繁體中文與台灣用語，包含資料表、欄位、多表透視與資料字典的顯示名稱與說明，主題領域名稱，以及關係圖上的文字。轉換有下列規則：

- 代碼（表名、欄位名）、預設值、資料庫連線與專案名稱不會轉換。
- 原本就是繁體中文的文字不會變動。
- 轉換結果在下次儲存時寫回專案檔案。第一次以繁體中文開啟簡體專案前，請先備份專案檔案。
- 三個參考範本開啟時會整份轉成繁體中文。

介面是 English 時，只有內建設定的名稱會換成英文，模型內容維持原樣。

## 11. 快捷鍵

macOS 用 Cmd，Windows 用 Ctrl。表格中寫成 Cmd/Ctrl。

### 11.1 全域

| 按鍵 | 作用 |
|------|------|
| Cmd/Ctrl + S | 儲存專案 |
| Cmd/Ctrl + `+` 或 `=` | 放大整個介面 |
| Cmd/Ctrl + `-` | 縮小整個介面 |
| Cmd/Ctrl + `0` | 介面恢復原始大小 |
| Esc | 關閉可關閉的對話框 |

### 11.2 關係圖

| 按鍵 | 作用 |
|------|------|
| Cmd/Ctrl + C、Cmd/Ctrl + V | 複製、貼上選取的物件 |
| Cmd/Ctrl + Z | 復原 |
| Cmd/Ctrl + Shift + Z | 重做 |
| Delete 或 Backspace | 刪除選取的物件 |
| 方向鍵 | 把選取的物件移動 1 像素 |
| Cmd/Ctrl + F | 顯示或隱藏「圖上找表」搜尋框 |
| Cmd/Ctrl + M | 顯示或隱藏小地圖 |
| Cmd/Ctrl + 滑鼠滾輪 | 縮放畫布 |
| Cmd/Ctrl + 拖曳 | 移動畫布 |

### 11.3 欄位清單與模型樹

| 按鍵 | 作用 |
|------|------|
| 點列號 | 選取一列 |
| Cmd/Ctrl + 點列號 | 跳著選取多列 |
| Shift + 點列號 | 選取連續的列 |
| Cmd/Ctrl + C、Cmd/Ctrl + V | 複製、貼上選取的列 |
| 方向鍵 | 在儲存格之間移動 |
| Cmd/Ctrl + Shift + U | 切換儲存格中英文的大小寫 |
| Cmd/Ctrl + 點擊、Shift + 點擊 | 在模型樹中多選、連續選取 |

### 11.4 報表的欄位版面設計

| 按鍵 | 作用 |
|------|------|
| Cmd/Ctrl + Z | 復原 |
| Cmd/Ctrl + Y | 重做 |

## 12. 已知限制與常見問題

**按了連線「測試」或逆向，出現找不到 JDK 的訊息。** 訊息以「未偵測到JDK」開頭時，表示 MyPD 找不到 Java。請安裝 Java，或到「設定」→「系統參數」→「JAVA_HOME」指定 Java 目錄，再按「測試」確認。詳細步驟請看 [安裝手冊](安裝手冊.md)。

**訊息以「未找到Java引擎檔案」開頭。** 安裝包缺少 Java 引擎檔案 `pdmaner-java.jar`。這不是您的設定問題，請回報給提供安裝包的人。

**逆向大型資料庫時出現記憶體不足。** 訊息會提示到「JVM參數」調整。請在「設定」→「系統參數」→「JVM參數」提高記憶體上限。

**錯誤訊息中提到記錄檔。** 連線與逆向失敗時，對話框會顯示記錄檔資料夾的位置，可以點連結開啟。

**PDM 檔案儲存後，資料字典或多表透視不見了。** PDM 檔案不保存這些內容，請看主手冊 5.2 節。編輯 PDM 時若加入了這類內容，請用「另存為」存成 `.pdma.json`。

**PDM 檔案沒有自動儲存。** 自動儲存刻意不寫回 PDM 檔案，請手動按「儲存」。

**開啟專案後，資料表與欄位的名稱從簡體變成繁體。** 介面是繁體中文時，MyPD 會把簡體中文的模型內容轉成繁體中文，並在下次儲存時寫回專案檔案，請看 10.5 節。代碼、預設值與資料庫連線不會變動。若不想保留轉換結果，請不要儲存，直接關閉專案。

**連線「測試」顯示 Login failed。** 這是資料庫拒絕了帳號或密碼，不是 MyPD 的錯誤。請重新輸入密碼，並確認輸入時 Shift 與 Caps Lock 的狀態。從 DBX 或 DBeaver 匯入的連線可能沒有密碼。

**DBX 匯入的連線沒有密碼。** DBX 的密碼已加密，無法讀取。請在「資料庫連線設定」自行填寫。

**連線匯入清單中有些項目不能選。** 標示「（不支援）」的連線，其資料庫類型 MyPD 不支援。

**逆向時看不到「資料庫」下拉清單。** 只有 MySQL、MariaDB、PostgreSQL 與 SQL Server 的連線可以選擇資料庫。其他資料庫請在連線的 url 中指定。

**「模型比較與合併」的連線清單看不懂。** 這個下拉清單顯示的是連線的內部代碼，不是連線名稱。清單的順序與「資料庫連線設定」中的連線順序相同，預設選取第一個連線。

**「模型比較與合併」或報表無法讀取 PDM 檔案。** 這兩個工具的「選擇檔案」與「新增模型檔案」只能讀取 JSON 格式的專案檔案。請先開啟 PDM，「另存為」`.pdma.json` 後再比較。

**參考範本不能使用版本管理。** MyPD 會顯示「參考案例無法使用版本管理功能，請先執行儲存操作！」。請先把範本另存為專案檔案。

**以唯讀模式開啟後看不到工具列。** 唯讀模式會隱藏工具列與「版本管理」頁籤。請關閉專案，再從首頁正常開啟。

**誤刪或改壞了模型，想回到之前的狀態。** 使用工具列的「操作歷史」，選一份儲存時的快照「還原」，再儲存專案。若是 PDM 檔案，原始內容在同目錄的 `.pdm.bak` 中。

**MyPD 當掉後，專案資料還在嗎？** 視窗當掉或沒有回應時，MyPD 會在專案資料夾寫出 `<專案名>-backup-<時間>.chnr.json`。這是一般的專案檔案，可以從首頁「開啟」。
